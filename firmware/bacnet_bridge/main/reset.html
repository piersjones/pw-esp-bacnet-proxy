Setup & Reset

Setup Wizard

Rerun the interactive setup wizard to re-discover BACnet devices, reassign rooms, or update MQTT broker details.

Reconfigure WiFi

Clears saved WiFi credentials and restarts into SoftAP setup mode (ESP-BACnet-Setup). Does not touch the /update firmware password.

Factory Reset

Clears all stored configuration (WiFi, BACnet targets, custom room names, MQTT broker settings, and the /update firmware password) from flash memory. Forgot that password? This is how you recover it wirelessly, no USB required: factory reset clears it back to unconfigured, then Step 1 of the Setup Wizard lets you choose a new one.
